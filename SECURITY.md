# Security policy

Relational Fixture Slice is development version 0.1.0. The supported security scope is the current development code and the restricted contract in docs/contract.md; there is no production-readiness, certification or response-time guarantee.

Report suspected vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/martinlofranodeoliveira/relational-fixture-slice/security/advisories/new).

Include the affected code path, actual Python/PostgreSQL versions, a synthetic reproduction, expected boundary and observed behavior. Do not send credentials, private database records or client code. Please avoid public disclosure of exploit details while discussing a report privately.

Important boundaries: payload is not anonymized; bundle hashes are not signatures; trusted directory parents and exclusive target use are required; statement/byte limits are not hard memory/disk quotas. See docs/security-model.md for defenses and exclusions.

For general contact, use the official homepage: https://lofranotecnologia.com.br .
